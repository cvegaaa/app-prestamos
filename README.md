# App de Préstamos

Aplicación web para gestión y control de préstamos personales.

## Qué resuelve

Permite administrar clientes, préstamos, cuotas y gastos desde un panel único, con un dashboard general del estado de la cartera.

## Módulos

- **Dashboard** — resumen general.
- **Clientes** — gestión de clientes.
- **Préstamos** — registro y seguimiento de préstamos.
- **Cuotas** — control de pagos e installments.
- **Gastos** — registro de gastos asociados.
- **Admin** — panel administrativo.

## Stack técnico

- React + TypeScript + Vite
- Tailwind CSS
